# somansingh.com

Static, single-page version of Soman Singh's portfolio. The visual design, typography, imagery, and content follow the original WordPress site, while the hero slideshow uses a continuous two-layer dissolve and alternating slow zoom.

## Local preview

The project is configured for Laravel Herd at:

`C:\herd\sites\somansingh.com`

Open [http://somansingh.com.test](http://somansingh.com.test) in a browser.

## Structure

- `index.html` — single-page content and navigation
- `styles.css` — local fonts, source-matched layout, and responsive styles
- `script.js` — hero slideshow and mobile navigation
- `assets/` — local fonts and images
